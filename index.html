Project Description

What is NG PULSE?

NG PULSE is a rail-signature workload integrity monitor — a hardware security device designed to detect when a processor is behaving anomalously by watching its supply-rail current draw in real time. Modern defense systems face hardware-level threats that software-layer defenses cannot stop: fault injection attacks, malicious firmware substitution, supply-rail manipulation, and clock glitching can all compromise a processor without triggering any software alarm. NG PULSE addresses this gap by passively monitoring the power signature of a host RISC-V processor using a shunt resistor and instrumentation amplifier, digitizing that signature through the onboard ADC of a Nordic nRF52832 MCU, and processing rolling windows of samples on a BASYS 3 FPGA to extract statistical features — mean, variance, and peak-to-peak amplitude. Those features are compared against a stored golden profile derived from known-good operation; deviations above defined thresholds assert a hardware flag that the MCU translates into a graduated response ranging from event logging and BLE telemetry through processor reset to full supply-rail power cutoff. The monitor is physically independent of the processor it protects and cannot be disabled by compromising the software running on it.

Technical Background

What NG PULSE protects against

NG PULSE is a hardware security primitive. It guards the physical execution environment — not software logic. The threat model is an adversary with physical access to the hardware.

Hardware threats
Fault injection
Voltage glitches, EM pulses, or laser shots that force the processor into unintended states. These cause sudden current spikes that push the feature vector outside the trained normal region.
Malicious firmware
Unauthorized code runs a different instruction mix. The workload fingerprint shifts away from the golden profile and sustains an anomalous signature across multiple detection windows.
Supply rail manipulation
An attacker injecting current into the supply rail produces readings that exceed anything a legitimate workload could generate. The comparator flags this immediately.
Clock glitching
Manipulating the clock signal skips or repeats instructions, creating chaotic pipeline behavior. The variance of the current draw spikes — exactly what the sliding variance register detects.
Detection approach

Every workload has a characteristic power signature. NG PULSE learns what normal looks like, then flags deviations — without ever needing to decode individual instructions.

The classifier compares two things: a sliding reference that updates each window to catch sudden changes, and a fixed golden reference loaded at boot to catch drift from the known-good baseline.

ALERT# — Minor flag
Variance drift above threshold. Three consecutive flags trigger processor reset.
CRITICAL# — Major flag
P2P spike past golden threshold. Immediate reset, then power kill after M resets.
